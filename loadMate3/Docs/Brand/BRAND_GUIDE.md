# Lyneqo Light-First Brand Guide

## Direction

Lyneqo is light, calm and approachable. Dark mode is supported, but it is not the defining visual identity.

## Visual principles

- Use pale neutral backgrounds and white cards.
- Keep deep navy for headings, navigation and structure.
- Use teal sparingly for primary actions and selection.
- Use green, amber and red only for genuine status.
- Avoid glowing cyan lines, heavy gradients and dark full-screen dashboards.
- Use 16–20 pt card corner radii.
- Use subtle shadows only in light mode.
- Let information hierarchy come from spacing and typography rather than colour saturation.

## Dark mode

- Use near-black blue backgrounds, not pure black.
- Cards should remain visibly separate.
- Reduce glow and gradients.
- Keep the same product accent but soften saturation.
- Preserve contrast and Dynamic Type.
